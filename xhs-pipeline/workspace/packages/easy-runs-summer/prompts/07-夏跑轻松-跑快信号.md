# 07-夏跑轻松-跑快信号

Create a Xiaohongshu style infographic.

## Image Specifications
- Portrait 3:4, Chinese hand-drawn text.
- Hand-drawn/cartoon infographic, no realistic elements.
- Checklist layout, clear warning signals.

## Style
Sketch-notes, warm cream background, macaron sticky notes, coral red warning labels, green check for the takeaway.

## Text Content
Use only this text:
- 跑太快的信号
- 腿越来越沉
- 睡眠变差
- 心率压不住
- 下一次训练提不起劲
- 轻松跑要服务下一次训练

## Visual Concept
Female cartoon runner sits beside a track reading training notes. Four red reminder sticky notes around her with the symptoms. Bottom has one green note with the conclusion. Keep emotional tone gentle and practical.

## Watermark
Include a subtle watermark "秋海" in the bottom-right corner. Small, legible, low-contrast, elegant, not distracting.
