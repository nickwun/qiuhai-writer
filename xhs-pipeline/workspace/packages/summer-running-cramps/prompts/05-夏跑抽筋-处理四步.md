# 05-夏跑抽筋-处理四步

Create a Xiaohongshu style infographic.

## Image Specifications
- Portrait 3:4 Xiaohongshu image card.
- Chinese hand-drawn text only.
- Hand-drawn/cartoon infographic, no realistic elements.
- Flow layout with four steps.

## Xiaohongshu Visual Taste
Sketch-notes style, warm cream paper, macaron flow nodes, tree shade, water bottle, gentle stretch icon.

## Text Content
Use only this text:
- 抽筋时先做 4 步
- 1 停下来
- 2 到阴凉处
- 3 轻柔拉伸
- 4 小口补水和电解质
- 别立刻恢复原计划

## Visual Concept
Mixed male and female cartoon runners in shade handling a calf cramp: stop running, sit in shade, gently stretch calf, sip water/electrolyte. Four connected nodes with arrows. Avoid dramatic injury look.

## Watermark
Include a subtle watermark "秋海" in the bottom-right corner. Small, legible, low-contrast, elegant, not distracting.
