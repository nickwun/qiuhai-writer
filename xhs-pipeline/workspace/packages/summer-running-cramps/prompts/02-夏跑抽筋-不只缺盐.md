# 02-夏跑抽筋-不只缺盐

Create a Xiaohongshu style infographic.

## Image Specifications
- Portrait 3:4 Xiaohongshu image card.
- Chinese hand-drawn text only.
- Hand-drawn/cartoon infographic, no realistic elements.
- Comparison layout, moderate density.

## Xiaohongshu Visual Taste
Warm cream paper background, macaron sticky notes, hand-drawn question mark, sweat and fatigue icons, coral accent for key warning.

## Text Content
Use only this text:
- 缺盐？可能，但不一定
- 可能有关：大量出汗
- 可能有关：电解质丢失
- 但不是：唯一答案
- 补了电解质还抽，要看别的原因

## Visual Concept
Male cartoon runner holding an electrolyte bottle with a big question mark. Left side shows sweat and salt marks. Right side shows fatigue, high intensity, muscle control icons. Clear but not crowded.

## Watermark
Include a subtle watermark "秋海" in the bottom-right corner. Small, legible, low-contrast, elegant, not distracting.
