# 02-湿球黑球-只看温度

Create a Xiaohongshu style infographic.

## Image Specifications
- Portrait 3:4 Xiaohongshu image card.
- Chinese hand-drawn text only.
- Hand-drawn/cartoon infographic, no realistic elements.
- Comparison layout, moderate density.

## Xiaohongshu Visual Taste
Warm cream paper background, macaron sticky notes, coral accents, hand-drawn arrows, thermometer and dashboard icons.

## Text Content
Use only this text:
- 气温不等于风险
- 气温：空气有多热
- WBGT：身体散热有多难
- 跑步更该看后者

## Visual Concept
Left side: small thermometer labeled 气温. Right side: larger heat pressure dashboard labeled WBGT. Male cartoon runner stands between them, choosing the right dashboard. Clear comparison arrows.

## Watermark
Include a subtle watermark "秋海" in the bottom-right corner. Small, legible, low-contrast, elegant, not distracting.
