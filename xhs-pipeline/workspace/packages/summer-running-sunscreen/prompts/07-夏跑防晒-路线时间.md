# 07-夏跑防晒-路线时间

## 图片目标

强调路线和时间也是防晒的一部分，同样距离下暴晒路线和树荫路线不是同一种压力。

## 画面比例

竖版 3:4。

## 风格

柔和手绘信息图，小红书跑步科普卡片风格，米白背景，浅蓝、薄荷绿、浅橙、淡粉点缀。

## 主视觉

手绘路线对比图：左边是无遮挡大马路和强太阳，右边是树荫公园路线。男女卡通跑者选择树荫路线，路线图上有时钟、太阳、树荫和“路线 B”小标签。

## 页面文字

- 主标题：路线和时间，也是防晒
- 少跑连续暴晒
- 优先树荫 / 公园
- 避开正午长时间户外
- 水泥路和水边会反光
- 留一个缩短路线方案

## 人物安排

男女跑者同时出现，作为路线选择的辅助人物，不抢路线图。

## 构图要求

标题顶部最大；中间路线对比清楚；左边暴晒、右边树荫形成明确差异；文字不超过五个短句。右下角加入小而低调的“秋海”水印。

## 避免事项

不要画成复杂真实地图；不要展开补水、电解质或中暑主题；不要让装饰元素太多。
