# qiuhai-writer

一个用于中文长文写作的风格化写作 skill，目标不是只模仿表面语气，而是稳定复现一种写法：

**从具体事件进入，呈现真实反应，辨认自身动机，完成一次克制、诚实、带留白的自我拆解。**

一句话概括：

> 用平实克制的第一人称叙述，把外部事件写成一次内心辨认。

---

## 适用场景

- 第一人称随笔
- 公众号文章
- 生活观察类写作
- 跑步主题文章
- 家庭 / 育儿反思类文章
- 个人经验复盘
- 从零散素材整理成成熟成稿
- 风格化改写
- 根据经历生成自述型文章

不适用于：

- 纯资讯稿
- 新闻播报体
- 商品带货文案
- 强销售转化文案
- 高刺激爆款口播稿
- 强戏剧化、强反转故事文
- 过度鸡血、过度煽情文
- 纯知识科普型文章
- 完全客观、去人格化写作

## 这个 skill 的重点不是“文风像”，而是“写法像”

它关注的不只是：

- 用什么词
- 怎么分段
- 句子像不像公众号

它更关注：

- 是否从具体生活切口进入
- 是否写出了真实反应
- 是否保留了不体面的部分
- 是否出现了自我纠偏
- 是否避免了说教、鸡汤、模板味
- 是否保留“真实的人在梳理自己”的感觉

---

## 使用建议

最推荐的使用方式不是把它当成“自动出稿器”，而是把它当成：

- 风格约束器
- 结构整理器
- 去 AI 味编辑器
- 终稿质检器

这样稳定性会更高。
