# 06-夏跑防晒-装备选择

## 图片目标

说明帽子、衣物、太阳镜不是装饰，而是夏跑防晒组合的一部分。

## 画面比例

竖版 3:4。

## 风格

柔和手绘信息图，小红书跑步科普卡片风格，米白背景，浅蓝、薄荷绿、浅橙、淡粉点缀。

## 主视觉

男性卡通跑者在门口检查跑步装备，旁边三栏装备卡：帽子、衣物、太阳镜。衣物画成浅色轻薄跑步上衣，太阳镜有小标签“UV 防护”，帽子旁标注“耳朵后颈别忘”。

## 页面文字

- 主标题：帽子衣物太阳镜，不是装饰
- 帽子：别忘耳朵和后颈
- 衣物：轻薄、透气、排汗
- 颜色：浅色更友好
- 太阳镜：看 UV 防护
- 不是越少穿越凉

## 人物安排

男性跑者作为装备检查者，人物友好自然，装备模块为主。

## 构图要求

标题顶部最大；三栏装备卡清楚平衡；不要像购物清单，保持科普信息图质感。右下角加入小而低调的“秋海”水印。

## 避免事项

不要出现真实品牌、商品 logo、价格标签、购买暗示；不要把装备画得过于商业化；不要出现外部出处说明。
