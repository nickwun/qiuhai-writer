# 03-夏跑中暑-热衰竭信号

Create a Xiaohongshu style infographic.

## Image Specifications
- Portrait 3:4 Xiaohongshu image card.
- Chinese hand-drawn text only.
- Hand-drawn/cartoon infographic, no realistic elements.
- Checklist layout with five warning notes.

## Xiaohongshu Visual Taste
Sketch-notes style, warm cream background, macaron sticky notes, coral warning highlights, soft icons, not frightening.

## Text Content
Use only this text:
- 热衰竭信号
- 大量出汗
- 头晕头痛
- 恶心想吐
- 发虚、发冷
- 动作开始不稳

## Visual Concept
Female cartoon runner stands in tree shade, slightly uncomfortable but safe. Five warning sticky notes with icons: sweat drops, dizzy stars, stomach discomfort, chills, unstable footsteps. Text large and readable.

## Watermark
Include a subtle watermark "秋海" in the bottom-right corner. Small, legible, low-contrast, elegant, not distracting.
