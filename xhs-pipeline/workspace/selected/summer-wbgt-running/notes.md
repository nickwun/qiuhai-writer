# Notes

## 核心观点

夏天跑步不能只看天气 App 上的普通气温。普通温度告诉你空气多热，但不一定能反映身体散热有多难。湿球黑球温度（WBGT）把气温、湿度、阳光辐射、风等因素放在一起，更接近跑者在户外真正承受的热压力。

## 和已做选题的区别

- 不讲“为什么心率高一截”。
- 不讲 Zone 2 或低心率。
- 不讲热适应。
- 不讲补水越多越好。
- 不讲夏天慢秋天快。
- 本篇重点是：出门前如何判断今天适不适合跑、该怎么调整训练安排。

## 文章结构建议

1. 夏天有时气温不高，但跑起来异常难受。
2. 普通气温、体感温度、WBGT 的区别。
3. WBGT 为什么更适合跑者看。
4. 用几个区间给出跑步调整建议。
5. 没有 WBGT 数据时，用温度、湿度、太阳、风来近似判断。
6. 最后强调：能不能跑，不只看天气好不好，而是看身体能不能安全散热。
