# topic samples

## 题材一：跑步反思

### 样本 A：认可 / 跑团 / 外界评价
后来我才知道，一队有位成员因为要上夜班无法参赛，我算是临时替补入局。虽然替补入选让我心情有点复杂，但说实话，当真正被拉进一队的群里时，我心里还是掠过了一丝窃喜。

这丝窃喜让我不得不重新审视自己。我曾以为自己已经可以完全屏蔽外界的声音。但事实证明，我依然是个俗人。

### 样本 B：成绩 / 找补 / 自欺
不过我并不想归咎于跑团跑友，毕竟他们也是出于善意，才对我表达肯定。声音都一样，是不是干扰，其实只在自己一念之间。

因为结果不如预期，我对最终成绩失望，才需要一个理由，把外界声音当成干扰。

### 样本 C：执念 / 证明自己
如今回头看，当时我似乎不是在跑步，我是把跑步当成一种证明方式：证明自己还可以，证明自己在前进，证明自己没有停下。

外人或许看不出来，但我知道：这更多是执念，不是热爱。

## 题材二：家庭 / 育儿 / 关系

### 样本 A：说教 / 共情 / 动机
实际上我也不希望孩子去麻将馆。但看到她们一起把矛头指向我，好像我在故意放纵孩子一样，内心突然升起一阵烦躁与不耐烦。

后来想起这一幕，我突然就能共情到孩子，了解他平日面对大人说教时的心情。

### 样本 B：情绪背后的动机
我的眼里和脑子里，都只能看见她的行为，她在生气，她在宣泄，她在找盟友。

但在这些行为背后，她们的动机是什么，我却完全看不见。真要说起来，我们的出发点应该是一样的。

### 样本 C：身份 / 联结 / 陪伴
为什么过去我会对孩子的哭闹无动于衷？很重要的原因是，那时我还没有做好接受「父亲」这个身份的心理准备。

直到后来，当我看着一个小婴儿在眼皮底下一天天长大，才渐渐跟他建立起联系。

## 题材三：写作 / 公众号 / 自我表达

### 样本 A：写作不是轻松的事
写文章对我而言，依然不是件容易的事。大多数时候，在动手写之前，我都不知道该写些什么，经常枯坐在电脑屏幕前冥思苦想。

### 样本 B：只写自己真正想写的
刚重启公众号那段时间，我也会每天关注阅读量多少，和粉丝增减。后来，随着越写越久，我对各种数据也越发看淡。我只写自己真正想写的，其他的事情都不太在意。

### 样本 C：表达欲转移
虽然朋友圈越发越少，文章却越写越多。因此，消退的似乎并不是表达欲。它一直都在，只是换了个出口，从朋友圈转移到了公众号。

## 题材四：日常观察 / 社交观察

### 样本 A：跑步与打麻将
起初我以为跑步与打麻将没有什么区别，都能用来打发无聊、打发时间。

但再想想，似乎又有些不对劲。虽然我不打麻将，可是我跑步十多年，难道不懂跑步吗？

### 样本 B：群体 / 从众 / 不合群
复制粘贴就是一种从众心理。看到群里其他人都在发，无形之中会产生心理压力，迫使自己也加入进去。

不过，我要更悲观一些。就算是相互珍视的关系，也不会一辈子都持续下去。

### 样本 C：主动打招呼 / 被拒绝
我不主动打招呼，主要是担心打过招呼后，对方没反应。我先释放善意，但别人不领情，一方面会感到浪费善意，一方面又会感到被拒绝。

不过这个想法并没有很快消失，它像一颗种子埋在心里。
