# 内容分析

## Target Audience

- **主要人群**：夏天长距离、越野、马拉松训练中容易抽筋的跑者。
- **次要人群**：习惯把抽筋归因于缺盐、赛前猛补电解质的新手和进阶跑者。
- **核心痛点**：抽筋后只想到补盐，却忽略热压力、疲劳、强度和肌肉耐受。

## Hook Analysis

**标题钩子评分**：⭐⭐⭐⭐⭐

- 反常识：抽筋不一定只是缺盐。
- 痛点明确：夏季跑步、长距离后半程、小腿大腿抽筋。
- 收藏价值：原因清单、现场处理、预防方法。
- 分享触发：适合发给容易在长跑或比赛后半程抽筋的跑友。

## Value Proposition

用户看完后应获得：

1. 知道缺盐只是抽筋的一个可能因素。
2. 理解疲劳、强度、热压力和肌肉耐受也会增加抽筋风险。
3. 知道抽筋时要停跑、阴凉、轻柔拉伸、小口补水和降温。
4. 能从补给、配速、力量、训练负荷和抽筋模式上减少下一次发生。
