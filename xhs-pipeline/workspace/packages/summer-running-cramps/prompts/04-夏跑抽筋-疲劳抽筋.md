# 04-夏跑抽筋-疲劳抽筋

Create a Xiaohongshu style infographic.

## Image Specifications
- Portrait 3:4 Xiaohongshu image card.
- Chinese hand-drawn text only.
- Hand-drawn/cartoon infographic, no realistic elements.
- List layout with four scenario cards.

## Xiaohongshu Visual Taste
Warm cream paper, macaron scene cards, small route and slope icons, coral warning accents.

## Text Content
Use only this text:
- 疲劳型抽筋很常见
- 长距离后半程
- 比赛冲刺
- 爬坡下坡多
- 没练过的强度
- 不是补盐就能解决

## Visual Concept
Male cartoon runner near a long-run route marker feeling calf tightness. Around him four small scene cards: late long run, sprint finish, hill route, unfamiliar intensity. Keep it practical.

## Watermark
Include a subtle watermark "秋海" in the bottom-right corner. Small, legible, low-contrast, elegant, not distracting.
