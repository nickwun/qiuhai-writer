# 内容分析

## Target Audience

- **主要人群**：夏天仍然坚持户外跑的业余跑者，尤其是只看天气 App 气温就决定训练的人。
- **次要人群**：长距离、节奏跑、间歇跑训练者，以及容易在闷热天气跑崩的跑者。
- **核心痛点**：气温看起来不高，但跑起来特别闷、特别累，不知道今天到底适不适合跑。

## Hook Analysis

**标题钩子评分**：⭐⭐⭐⭐⭐

- 反常识：夏天跑步不是只看温度。
- 新知识点：湿球黑球温度 / WBGT。
- 实用价值：出门前判断热风险，决定是否降强度、改时段、改室内。
- 收藏价值：WBGT 分级 + 没有数据时的四项替代判断。

## Value Proposition

用户看完后应获得：

1. 明白普通气温只说明空气多热，不等于身体散热难度。
2. 知道 WBGT 更接近跑者实际承受的热压力。
3. 能用 WBGT 参考区间调整训练。
4. 没有 WBGT 数据时，也能看湿度、太阳、风和路线退路。
