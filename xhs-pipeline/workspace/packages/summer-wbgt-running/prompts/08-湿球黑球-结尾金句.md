# 08-湿球黑球-结尾金句

Create a Xiaohongshu style infographic.

## Image Specifications
- Portrait 3:4 Xiaohongshu image card.
- Chinese hand-drawn text only.
- Hand-drawn/cartoon infographic, no realistic elements.
- Sparse ending quote card.

## Xiaohongshu Visual Taste
Warm cream paper, mint and peach accents, shaded running path, safety route arrows, gentle hopeful mood.

## Text Content
Use only this text:
- 安全不是训练之外的事
- 它本身就是训练的一部分
- 会判断环境，才能稳定跑完整个夏天
- 你跑前会看湿度吗？

## Visual Concept
Evening shaded running path. Mixed male and female cartoon runners slow down and look at a route sign with shade and return arrows. Big central quote, small interaction line near bottom above safe zone.

## Watermark
Include a subtle watermark "秋海" in the bottom-right corner. Small, legible, low-contrast, elegant, not distracting.
