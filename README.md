# qiuhai-writer

一个用于中文写作协作的 skill 仓库，核心主题是“秋海风格写作”。这个仓库的默认主文件是 [SKILL.md](./SKILL.md)。

## 仓库是什么

`qiuhai-writer` 提供的不是通用文案模板，也不是“帮你写得更像某种网文风格”的提示词合集，而是一套可复用的写作约束文件。它主要解决三件事：

- 在 AI 协作中稳定调用“秋海风格写作”
- 明确写作边界，避免伪造经历、滥用情绪和过度模仿
- 让同一套风格规则可以被持续复用、维护和迭代

如果只默认引用一个文件，请使用 [SKILL.md](./SKILL.md)。

## 适用场景

- 需要改写、起草或整理中文文章，并保持稳定的风格基线
- 需要把零散素材组织成克制、自然、可阅读的文本
- 需要在团队或长期项目中复用同一套写作约束
- 需要把“风格”“边界”“自检标准”沉淀成可维护文件

## 不适用场景

- 追求高转化营销语气、情绪煽动、口号式表达的文案
- 需要机械复制某位真实作者人生经历或私密语料的任务
- 事实精度优先的法律、医疗、学术、说明文类文本
- 只是做泛化润色，而不需要明确风格约束的普通写作任务

## 文件用途

- [SKILL.md](./SKILL.md)：主 skill 文件。默认引用入口，定义适用范围、核心原则、风格模仿指南、AI 协作边界、反向约束、四层自检体系、执行规则和提示词模板。
- [README-skill-usage.md](./README-skill-usage.md)：使用说明。解释这个 skill 该在什么时候调用、不该怎么用、如何组织协作流程，以及如何判断一次调用是否成功。
- [examples.md](./examples.md)：调用示例。提供可直接复制的提示词示例，包括改写现有文章、整理零散素材、先出提纲再成稿和最短系统提示版。
- [LICENSE](./LICENSE)：仓库许可协议。
- [.gitignore](./.gitignore)：本仓库的忽略规则。

## 使用建议

1. 先读 [SKILL.md](./SKILL.md)，确认主规则与边界。
2. 再读 [README-skill-usage.md](./README-skill-usage.md)，确认推荐工作流。
3. 最后参考 [examples.md](./examples.md) 组织具体调用。

仓库首页只负责说明仓库用途。真正作为默认引用文件使用的，仍然是 [SKILL.md](./SKILL.md)。
