# qiuhai corpus

这套 corpus 不是“文章全集”，也不是一份写作教材。

它更像一个拆开的语料夹：

- 固定作者已经出现过的说法
- 固定作者常用的句子动作
- 固定作者会怎么转弯、怎么收尾
- 在素材不足时，尽量少让模型自己发挥

## 文件说明

- `style-samples.md`：开头、转弯、自我纠偏、收尾的短样本
- `phrase-bank.md`：连接词、回撤词、情绪说法、自我修正说法、收尾说法
- `sentence-moves.md`：句子常怎么起、怎么拐、怎么往回收
- `endings.md`：更像作者的收尾，和不推荐的收尾
- `anti-patterns.md`：黑名单词、黑名单句式、黑名单情绪命名、常见失真点
- `topic-samples.md`：按题材整理的短样本
- `material-to-final-samples.md`：素材加工成稿的短对照样本

## 用法

真正写作时，优先看当次素材。

如果用户已经给了：

- 语音转录
- 零散素材
- 当下记录
- 原始表达

优先保留那些原始说法。

这套 corpus 主要用在这些时候：

- 起手不像作者
- 转弯不像作者
- 情绪说法太像模型
- 结尾抬起来了
- 素材不够，只能先借已有表达模式托底
- 素材太散，需要看如何压缩、重排、合并成稿
