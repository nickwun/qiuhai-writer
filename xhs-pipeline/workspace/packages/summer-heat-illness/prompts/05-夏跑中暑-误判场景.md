# 05-夏跑中暑-误判场景

Create a Xiaohongshu style infographic.

## Image Specifications
- Portrait 3:4 Xiaohongshu image card.
- Chinese hand-drawn text only.
- Hand-drawn/cartoon infographic, no realistic elements.
- List layout with three scene cards.

## Xiaohongshu Visual Taste
Sketch-notes style, warm cream background, macaron scene cards, small exclamation icons, clean educational tone.

## Text Content
Use only this text:
- 最容易误判的 3 个场景
- 长距离后半程
- 比赛或团跑
- 跑完以后
- 记住：不舒服别全归因于累

## Visual Concept
Female cartoon runner looks at a training calendar. Three small scene cards: long-run route marker, group run, post-run sitting in shade. Each card has a tiny warning icon. Keep layout easy to scan.

## Watermark
Include a subtle watermark "秋海" in the bottom-right corner. Small, legible, low-contrast, elegant, not distracting.
