# 05-夏跑防晒-跑中补涂

## 图片目标

说明长时间户外跑要提前规划补涂，不要等晒痛才想起来。

## 画面比例

竖版 3:4。

## 风格

柔和手绘信息图，小红书跑步科普卡片风格，米白背景，浅蓝、薄荷绿、浅橙、淡粉点缀，信息清楚但不拥挤。

## 主视觉

男女卡通跑者在公园补水点旁短暂停下，一人小口喝水，一人自然补涂耳朵和后颈。旁边有一条简化路线和补涂节点，小贴纸写“60-90 分钟以上先规划”。

## 页面文字

- 主标题：长时间户外跑，要想补涂
- 汗会带走一部分
- 擦汗也会蹭掉
- 60-90 分钟以上先规划
- 耳朵 / 脖子 / 手背优先补
- 不要等晒痛才想起

## 人物安排

男女跑者同时出现，人物辅助说明动作，不抢文字。

## 构图要求

标题最清楚；补涂节点和文字分区明确；“60-90 分钟以上”作为小贴纸，不要像绝对公式。右下角加入小而低调的“秋海”水印。

## 避免事项

不要画成防晒产品广告；不要出现品牌瓶身；不要把补涂写成强制公式；不要出现来源平台或外部 logo。
