# 02-夏跑防晒-为什么漏晒

## 图片目标

解释跑者为什么比普通出门更容易晒漏：时间长、汗多、擦汗、边角位置漏涂、阴天也有 UV。

## 画面比例

竖版 3:4。

## 风格

柔和手绘信息图，小红书跑步科普卡片风格，米白背景，低饱和浅蓝、薄荷绿、浅橙、淡粉配色。

## 主视觉

一位女性卡通跑者站在夏季跑步路线旁，周围围绕五个小贴纸模块：计时器、汗滴、擦汗毛巾、耳朵和后颈标记、云后太阳和 UV 标签。整体像“漏晒原因地图”。

## 页面文字

- 主标题：跑者更容易晒漏
- 跑得久
- 汗会冲掉
- 擦汗会蹭掉
- 耳朵和后颈常漏
- 阴天也可能有 UV

## 人物安排

女性跑者作为引导人物，表情清爽自然，不抢信息模块。

## 构图要求

主标题在顶部最大；五个原因模块大小接近、分布均衡；每个模块只放短词和简洁图标。右下角加入小而低调的“秋海”水印。

## 避免事项

不要排成长段文字；不要出现来源机构名称；不要用真实晒伤皮肤照片；不要画得像医疗科普海报。
