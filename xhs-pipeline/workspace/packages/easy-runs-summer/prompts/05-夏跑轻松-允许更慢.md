# 05-夏跑轻松-允许更慢

Create a Xiaohongshu style infographic.

## Image Specifications
- Portrait 3:4, Chinese hand-drawn text.
- Hand-drawn/cartoon infographic, no realistic elements.
- List layout with clear numbers.

## Style
Sketch-notes, warm cream paper, macaron mint and peach blocks, coral emphasis on seconds. Doodle thermometer, sun, stopwatch, running shoes.

## Text Content
Use only this text:
- 夏天慢一点很正常
- 慢 20 秒：可以
- 慢 40 秒：可以
- 慢 60 秒：也可以
- 跑完能恢复，就是对的配速

## Visual Concept
Female cartoon runner jogging calmly in tree shade. A big thermometer and stopwatch form the central motif. Three checklist rows for 20 秒、40 秒、60 秒, all with friendly check marks. Make the card reassuring, not alarming.

## Watermark
Include a subtle watermark "秋海" in the bottom-right corner. Small, legible, low-contrast, elegant, not distracting.
