# 06-湿球黑球-替代判断

Create a Xiaohongshu style infographic.

## Image Specifications
- Portrait 3:4 Xiaohongshu image card.
- Chinese hand-drawn text only.
- Hand-drawn/cartoon infographic, no realistic elements.
- Checklist layout with five lines.

## Xiaohongshu Visual Taste
Warm cream paper, macaron sticky notes, small icons for humidity, sun, wind, route map, soft check marks.

## Text Content
Use only this text:
- 没有 WBGT 怎么办？
- 湿度高不高？
- 太阳强不强？
- 有没有风？
- 路线能不能撤退？
- 两三项不理想，就别硬跑

## Visual Concept
Female cartoon runner checks phone and route map before leaving. Four checklist sticky notes: humidity, sun, wind, route escape. Bottom reminder note is gentle but firm. Keep text readable.

## Watermark
Include a subtle watermark "秋海" in the bottom-right corner. Small, legible, low-contrast, elegant, not distracting.
