# 07-湿球黑球-训练调整

Create a Xiaohongshu style infographic.

## Image Specifications
- Portrait 3:4 Xiaohongshu image card.
- Chinese hand-drawn text only.
- Hand-drawn/cartoon infographic, no realistic elements.
- List layout with three workout cards.

## Xiaohongshu Visual Taste
Sketch-notes style, warm cream background, macaron cards, hand-drawn arrows, training calendar stickers.

## Text Content
Use only this text:
- 这 3 种课最该改
- 长距离：缩短或改路线
- 节奏/间歇：降强度
- 午休跑：换时段
- 重点：保安全，不硬撑

## Visual Concept
Male cartoon runner rearranges a training calendar. Three sticky-note workout cards: 长距离, 节奏/间歇, 午休跑. Arrows show 改短, 改轻, 改时段. Gentle practical tone.

## Watermark
Include a subtle watermark "秋海" in the bottom-right corner. Small, legible, low-contrast, elegant, not distracting.
