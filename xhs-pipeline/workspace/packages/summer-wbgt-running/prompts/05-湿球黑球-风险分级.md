# 05-湿球黑球-风险分级

Create a Xiaohongshu style infographic.

## Image Specifications
- Portrait 3:4 Xiaohongshu image card.
- Chinese hand-drawn text only.
- Hand-drawn/cartoon infographic, no realistic elements.
- List layout with colored risk scale.

## Xiaohongshu Visual Taste
Sketch-notes style, warm cream paper, green-yellow-orange-red risk bar, macaron blocks, hand-drawn training plan icon.

## Text Content
Use only this text:
- WBGT 跑步参考
- 低于 21°C：正常训练
- 21-25°C：留意体感
- 25-28°C：降强度
- 28°C 以上：谨慎，必要时室内
- 31°C 以上：不建议户外跑

## Visual Concept
Male cartoon runner holding a training plan. A vertical colored risk scale from green to red with the WBGT ranges. Keep each range on a separate rounded label, concise and readable.

## Watermark
Include a subtle watermark "秋海" in the bottom-right corner. Small, legible, low-contrast, elegant, not distracting.
