# Notes

## 核心观点

夏天跑步抽筋，不一定只是缺盐。大量出汗和电解质丢失可能参与其中，但很多跑者抽筋更像是疲劳、强度、肌肉准备不足和热压力叠加的结果。真正有用的处理，不是抽筋后只补一粒盐丸，而是把补水、电解质、降温、降强度、训练适应和肌肉耐受一起看。

## 和已做选题的区别

- 不讲心率为什么升高。
- 不讲 Zone 2 或低心率。
- 不讲热适应。
- 不讲补水越多越好。
- 不讲 WBGT 和出门前天气判断。
- 不讲热衰竭和中暑识别。
- 本篇重点是：抽筋的多因素判断和跑者处理策略。

## 文章结构建议

1. 抽筋最容易被简化成“缺盐”。
2. 夏天为什么更容易抽筋。
3. 缺盐只是一个可能因素。
4. 疲劳和神经肌肉控制也很重要。
5. 现场处理应该怎么做。
6. 哪些情况不能只当普通抽筋。
7. 怎么减少下一次抽筋。
