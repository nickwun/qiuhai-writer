# 03-夏跑轻松-两种目的

Create a Xiaohongshu style infographic.

## Image Specifications
- Portrait 3:4, Chinese hand-drawn text.
- Hand-drawn/cartoon infographic, no realistic elements.
- Comparison layout, moderate information density.

## Style
Sketch-notes with macaron palette, sticky notes, soft hand-painted color blocks, small doodle icons.

## Text Content
Use only this text:
- 轻松跑有两种
- 恢复型：跑完更松
- 发展型：长期积累
- 目的不同，标准不同

## Visual Concept
Two sticky-note cards side by side. Female cartoon runner appears between them. Left card: relaxed jog, blood circulation icon, loose legs icon. Right card: calendar, tiny mitochondria icon, stable upward line. Clean hierarchy and generous spacing.

## Watermark
Include a subtle watermark "秋海" in the bottom-right corner. Small, legible, low-contrast, elegant, not distracting.
