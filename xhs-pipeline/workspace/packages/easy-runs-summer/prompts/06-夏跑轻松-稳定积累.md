# 06-夏跑轻松-稳定积累

Create a Xiaohongshu style infographic.

## Image Specifications
- Portrait 3:4, Chinese hand-drawn text.
- Hand-drawn/cartoon infographic, no realistic elements.
- Flow layout with connected nodes.

## Style
Sketch-notes, warm cream paper, macaron blue and mint route nodes, hand-drawn arrows, light calendar and footprint doodles.

## Text Content
Use only this text:
- 发展型轻松跑
- 目标：稳定完成
- 常见范围：45 到 60 分钟
- 前提：真的轻松
- 心率稳，呼吸稳，动作不散

## Visual Concept
Male cartoon runner follows a path across a weekly calendar. Footprints connect nodes: 45 分钟, 60 分钟, 睡眠, 恢复. Show a stable heart-rate line above the path. Educational and clean.

## Watermark
Include a subtle watermark "秋海" in the bottom-right corner. Small, legible, low-contrast, elegant, not distracting.
