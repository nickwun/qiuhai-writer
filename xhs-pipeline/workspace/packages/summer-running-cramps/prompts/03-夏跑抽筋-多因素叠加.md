# 03-夏跑抽筋-多因素叠加

Create a Xiaohongshu style infographic.

## Image Specifications
- Portrait 3:4 Xiaohongshu image card.
- Chinese hand-drawn text only.
- Hand-drawn/cartoon infographic, no realistic elements.
- Mindmap or puzzle layout.

## Xiaohongshu Visual Taste
Sketch-notes style, warm cream background, macaron puzzle pieces, simple icons, hand-drawn curved arrows.

## Text Content
Use only this text:
- 抽筋常是叠加题
- 出汗多
- 热压力
- 强度过高
- 肌肉疲劳
- 耐受不够

## Visual Concept
Female cartoon runner in center. Five puzzle pieces surround her: sweat drop, sun heat, speed gauge, tired muscle, strength icon. Puzzle pieces combine into a small label 抽筋风险. Clean hierarchy.

## Watermark
Include a subtle watermark "秋海" in the bottom-right corner. Small, legible, low-contrast, elegant, not distracting.
