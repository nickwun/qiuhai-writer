# 04-夏跑轻松-心率旋钮

Create a Xiaohongshu style infographic.

## Image Specifications
- Portrait 3:4, Chinese hand-drawn text.
- Hand-drawn/cartoon infographic, no realistic elements.
- Balanced layout, central visual metaphor.

## Style
Sketch-notes, warm cream background, macaron blocks, coral highlight for keywords, hand-drawn arrows and bubbles.

## Text Content
Use only this text:
- 心率区间不是开关
- 它更像：调光旋钮
- 不只问：有没有进二区
- 还要问：呼吸、体感、恢复

## Visual Concept
A large hand-drawn dial/knob labeled 一区、二区、三区 as a smooth gradient arc, not separate switches. Male cartoon runner adjusts the dial. Around the dial place three icons: breathing bubble, legs feeling, sleep moon. Avoid overcrowding.

## Watermark
Include a subtle watermark "秋海" in the bottom-right corner. Small, legible, low-contrast, elegant, not distracting.
