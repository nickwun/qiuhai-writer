# Notes

## 核心观点

夏天跑步防晒，最容易错的地方不是完全没涂，而是以为“出门前涂过一次”就够了。跑步和普通通勤不一样：时间更长、汗更多、擦汗更频繁，路线里还有水泥路面、操场、桥面、水边等反射场景。防晒霜只是防护的一部分，衣物、帽子、太阳镜、路线阴影和中途补涂同样重要。

## 和已做选题的区别

- 不讲长跑补水、水 / 钠 / 碳水。
- 不讲热衰竭和中暑危险信号。
- 不讲心率漂移、WBGT、湿热训练或热适应。
- 不讲夏天跑慢是不是退步。
- 本篇重点是：紫外线和跑者防晒流程。

## 文章结构建议

1. 夏跑防晒最常见误区：涂过一次就安心。
2. 跑步场景为什么更容易晒漏。
3. 防晒不只是防晒霜，而是一套组合防护。
4. 跑前要涂到哪些容易漏的位置。
5. 跑中为什么要补涂，以及怎样补得更现实。
6. 帽子、衣物、太阳镜的作用。
7. 路线和时间选择也属于防晒。
8. 结尾：防晒不是矫情，是把训练留给训练本身。

## 风险点

- 不要写成“涂某个 SPF 就一定不会晒伤”。
- 不要推荐品牌或商业防晒产品。
- 不要用恐吓式皮肤病表达。
- 不要让画面变成美妆防晒广告，重点保持跑步科普和户外训练场景。
