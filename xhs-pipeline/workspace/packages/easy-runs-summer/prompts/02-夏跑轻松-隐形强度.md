# 02-夏跑轻松-隐形强度

Create a Xiaohongshu style infographic.

## Image Specifications
- Portrait 3:4, Chinese hand-drawn text.
- Hand-drawn/cartoon infographic, no realistic elements.
- Comparison layout with two clear sides.

## Style
Sketch-notes, warm cream paper, macaron pastel blocks, coral red for warning highlights. Use hand-drawn divider, arrows, small sweat and watch icons.

## Text Content
Use only this text:
- 嘴上轻松跑
- 想象中：慢慢跑，恢复一下
- 现实中：心率飘高，越跑越疲
- 轻松跑先看负荷，不只看配速

## Visual Concept
Male cartoon runner in split-screen. Left side relaxed jogging with green check mark. Right side same runner sweating, watch heart rate turns red, tired face. Middle has hand-drawn lightning divider. Keep text concise and readable.

## Watermark
Include a subtle watermark "秋海" in the bottom-right corner. Small, legible, low-contrast, elegant, not distracting.
