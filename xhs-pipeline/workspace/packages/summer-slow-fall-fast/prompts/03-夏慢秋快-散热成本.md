# 03-夏慢秋快-散热成本

Create a Xiaohongshu style infographic.

## Image Specifications
- Portrait 3:4 Xiaohongshu image card.
- Chinese hand-drawn text only.
- Hand-drawn/cartoon infographic, no realistic elements.
- Balanced layout with one central body diagram.

## Xiaohongshu Visual Taste
Sketch-notes style, warm cream background, macaron blocks, small sweat, heart, muscle, skin, and humidity doodles.

## Text Content
Use only this text:
- 身体在加班散热
- 肌肉要氧气
- 皮肤要散热
- 湿度高，汗更难蒸发
- 同样配速，心率更容易飘

## Visual Concept
Female cartoon runner with two hand-drawn blood-flow routes: one to muscles for oxygen, one to skin for cooling. Above: humidity cloud, sweat drops, drifting heart-rate line. Make the diagram simple and readable.

## Watermark
Include a subtle watermark "秋海" in the bottom-right corner. Small, legible, low-contrast, elegant, not distracting.
