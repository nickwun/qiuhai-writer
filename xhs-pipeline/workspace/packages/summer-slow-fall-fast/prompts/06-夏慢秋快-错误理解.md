# 06-夏慢秋快-错误理解

Create a Xiaohongshu style infographic.

## Image Specifications
- Portrait 3:4 Xiaohongshu image card.
- Chinese hand-drawn text only.
- Hand-drawn/cartoon infographic, no realistic elements.
- Comparison layout with clear wrong/right contrast.

## Xiaohongshu Visual Taste
Sketch-notes style, warm cream paper, coral red for wrong side, mint green for correct side, hand-drawn check and cross icons.

## Text Content
Use only this text:
- 不是越苦越强
- 错误：硬顶配速，天天透支
- 正确：降强度，保恢复，能持续
- 关键：稳住，而不是硬撑

## Visual Concept
Male cartoon runner in two panels. Left: harsh sun, tired sprinting, red X. Right: early morning shade, steady easy running, green check. Make the contrast strong but still cute and clean.

## Watermark
Include a subtle watermark "秋海" in the bottom-right corner. Small, legible, low-contrast, elegant, not distracting.
